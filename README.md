# \# 论文精读 Agent (Paper Reader Agent)

# 

# 基于原生 Function Calling 工具调用架构的轻量级论文精读助手，大模型自主调用检索工具，回答均基于论文原文并标注页码，多维度抑制大模型幻觉。

# 

# \## 技术栈

# \- 核心架构：大模型原生 Function Calling 工具调用

# \- 检索方案：BM25 + Jieba 中文分词

# \- 大模型：DeepSeek-Chat

# \- PDF 解析：PyPDF2

# \- 开发语言：Python

# 

# \## 核心功能

# 1\.  自主工具调用：大模型作为决策中枢，可自主判断是否需要检索原文，实现标准 Agent 决策闭环，非固定流程调用。

# 2\.  页码溯源机制：所有回答标注对应原文页码，结论可反向验证，有效压缩大模型编造空间。

# 3\.  多维度幻觉治理：通过强制检索前置、系统提示词约束、低温度参数、单轮调用限制四重手段，从输入侧到输出侧双向抑制幻觉。

# 4\.  轻量化部署：无需向量数据库、无需本地大模型，仅需 API 密钥即可本地运行，启动快、依赖少，适配单篇论文精读场景。

# 5\.  多轮对话支持：保留上下文记忆，支持连续追问，适配深度精读场景。

# 

# &#x20;快速开始

# 

# 1\. 安装依赖

# 

# pip install -r requirements.txt

# 

# &#x20;2. 配置 API 密钥

# \- 复制项目根目录下的 .env.example文件，重命名为 .env

# \- 在 .env`文件中填入你的 DeepSeek API Key（密钥可在 DeepSeek 开放平台申请）

# 

# &#x20;3. 放入待读论文

# 将需要精读的 PDF 论文重命名为 `paper.pdf`，放入项目根目录。

# 

# &#x20;4. 运行项目

# python main.py

# 

# 启动后即可输入问题，开始论文精读。

# 

# &#x20;设计思路

# 项目采用「检索工具 + 大模型决策」的标准 Agent 架构：

# \- 大模型承担决策角色，根据用户问题自主判断是否调用检索工具，以及构造检索关键词

# \- 检索模块基于 BM25 实现关键词召回，文本块按滑动窗口切分并记录对应页码，单篇论文场景下召回精准、部署成本极低

# \- 最终回答严格基于检索到的原文片段生成，配合页码溯源约束，将大模型从「自由作答」限定为「基于原文整理输出」，从架构层面降低幻觉风险
